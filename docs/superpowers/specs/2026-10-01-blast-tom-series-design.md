# Blast Tom Series — 設計仕様（リポ構成・共通基盤・Gatling Tom v1）

日付: 2026-10-01
状態: レビュー待ち（ユーザー確認後に実装計画へ）
改訂: 初稿を製造・音響・整合性の 3 観点でレビューし、21 件の指摘を反映した（§9）。

## 1. 目的とスコープ

キャノンタム（オクタバン）から派生した **オリジナル設計のタム 3 機種**を、
パラメトリック CAD で設計し、町工場へ入稿できる STEP と 2D 図面、
および構成比較のための音響シミュレーションまでを 1 つの公開リポで扱う。

| 機種 | 概要 | 順番 |
|---|---|---|
| **Gatling Tom** | 6" ヘッド＋短いプレナム胴の下に、SUS パイプ 6 本の管束。ミニガンの意匠 | **1（本仕様の対象）** |
| Vulcan Tom | 細長い筒に丸穴が多数。バルカン砲のバレルジャケットの意匠 | 2（別仕様） |
| Magnum Tom | 18" シングルヘッドのフロアタム。3 本脚。リボルバーのシリンダーの意匠 | 3（別仕様） |

本仕様が決めるのは **(a) リポ構成、(b) 共通基盤 `drumcad`、(c) Gatling Tom v1** の 3 つ。
Vulcan / Magnum は共通基盤の契約（§4.4）に従って後日それぞれ仕様を書く。

### 1.1 スコープ外（v1 ではやらない）

- **管束の回転**。v1 は非回転。ヘッダープレートを胴底フランジにボルト留めする構造にして、
  回転ユニット（ベアリング入りの中間ブロック）を後から同じフランジに挟めるようにしておく（→ D-05）。
- **打撃で回る機構（ノック式カム）と電動回転**。ロマンはあるが v1 のコストに乗せない。
- **管 1 本ずつの差し替え**。管はヘッダープレートに溶接する。音の追い込みは製作前のシミュレーションと、
  製作中の「長めに作って切り詰める」で行い、製作後は管束（ヘッダープレート＋管）を丸ごと交換する（→ D-10, D-14）。
- **金属の鳴りのシミュレーション**。空気の共鳴だけを解く。金属の減衰は現物で確認する（→ §4.3）。
- **鏡面仕上げ**。v1 は #400 サテンに固定する（→ D-15）。
- **他機種の設計**。

### 1.2 成功基準

1. `uv run --project cad python cad/build.py gatling` 一発で、部品 STEP・組立 STEP・DXF/PDF 図面・
   `viewer.html`・BOM・工程数量表・共鳴表・wav が `cad/out/gatling-6-6[-PROVISIONAL]/` に出る。
2. 管の本数・外径・長さ・隙間比・クランプ位置を `params.py` の値 1 つで変えると、
   形（viewer）と音（wav）と質量・工程数量が同時に更新される。
3. 図面は町工場が読める（材料が引ける断面、溶接箇所と順序、仕上げ、既製品の型番と員数、平面度）。
4. 他者の製品に由来する寸法・写真・特許解析、および非公開の資料への参照が **一切含まれない**。
   検証手段: 固有語のリスト（テストの定数として `cad/tests/` に置く。本書には書かない）で `grep -ri` がリポ全体で 0 件であることをテストにする。

## 2. 決定事項（D-xx）

`docs/decisions.md` に同じ番号で記録する。覆した判断も残す。

| # | 決定 | 理由 |
|---|---|---|
| D-01 | **公開リポ・外部依存なし**。以前に自分用に書いた非公開の CAD 道具（出典つき寸法・図面・viewer）を抽出して一般化し、以後は本リポで独立に育てる | オリジナル作品として公開する。非公開の資料や道具への依存・参照は公開リポでは成立しない |
| D-02 | **ライセンス**: コード MIT、図面・STEP・画像 CC BY 4.0 | 参考にしてもらう前提で摩擦が最小 |
| D-03 | **材質 SUS304、仕上げは研磨** | 傷に強く、ステンレスの反射が狙い。アルミ＋硬質アルマイトは傷には強いがマットで光沢が出ない |
| D-04 | **設計順序 Gatling → Vulcan → Magnum** | Gatling が要素最多で、共通基盤の要求を洗い出せる |
| D-05 | **Gatling v1 は非回転。ヘッダープレートは胴底の外向きフランジにボルト留め** | 回転は部品より「合わせ」（同心精度・当たり取り）で工賃が増える。ボルト留めなら分解運搬・管束ごとの交換・後付け回転ユニットが無償で付く |
| D-06 | ~~マウントは胴を囲む水平の矩形クレードル（平角材フレーム）＋後端ハンドル~~ → **D-22 で覆した** | 当初の理由はミニガンの上部マウント枠の意匠。経緯は決定ログ |
| D-07 | **ダブルフープは意匠＋質量リング。構造レールにはしない** | 管束が下に垂れるため重心が遠く、フープ懸架ではテンションロッドに曲げが偏る。荷重は当て板から胴で受ける（D-22） |
| D-08 | **ラグは 6 個**。管 6 本と方位を揃える（ラグの種類は D-21 で覆した） | 当初案の円錐ラグは入手数が足りない。6 ラグで上から見てラグ・受金・管が一直線 |
| D-09 | **管は周囲 6 本、中心は空**（v1 は軸なし。v2 の回転軸の場所） | 中心管は構造が大きくなる |
| D-10 | **管クランプは 2 段（先端の厚板＋中間の環）。管はヘッダープレートに溶接し、1 本ずつは外さない** | ミニガンの決定的な意匠。先端クランプのボルトは管の間の意匠ボルト（実締結は溶接）。1 本ずつの差し替えは受けスリーブと嵌め合いが要り、コストに合わない |
| D-11 | **管の隙間の既定は外径の 0.4 倍**（比で持つ。38.1 mm なら 15.2 mm） | ミニガンの管束の比率。外径を振っても比が保たれる |
| D-12 | **音の検証は塩ビモックではなく音響シミュレーション**（numpy の自前実装を核、独立実装との照合をテストに含める） | 自作モックは負担が大きい。管は 1 次元で十分。プレナムと膜は結合系として解く |
| D-13 | **管・プレナム・膜を 1 つの結合系として固有値を解く**。両端開口の `n·c/2L` は容積 → ∞ の極限値、閉開管の `(2n+1)·c/4L` は容積 → 0 の極限値として回帰テストに使う | プレナム（約 1.8 L）は管内空気（約 2.7 L）より小さく、開口端（圧力節）にならない。当初の「両端開口の 1/2 波長」は二重計上だった |
| D-14 | **音の追い込みは (1) 製作前の sweep、(2) 管を長めに作り、中間・先端クランプを溶接する前に切り詰めて調整、(3) 製作後は管束ごと交換** | 溶接構造と「先端クランプを外して管を替える」は両立しない |
| D-15 | **仕上げは #400 サテン。管は研磨済みの市販パイプ（手すり用 #400 研磨管）を使い、溶接は見えない面から、溶接後は局所の酸洗いペースト＋手仕上げ** | 組立後は管の隙間に研磨機が入らない。曲げ・溶接した部品を鏡面にするのは現実的でない |
| D-16 | **ヘッダープレートは 6 mm。管は下から挿してプレナム側（上面）から溶接。フランジ合わせ面は溶接後に平面出し（平面度 0.3）、1 mm シリコーンガスケット** | 3 mm 板に管 6 本の全周溶接では皿状に歪み、気密面にならない |
| D-17 | **ヘッダープレートと胴底フランジは胴より大径（外径 ≈ 胴外径 + 40 mm）。ボルト円は胴の外側、方位は管に対して 30° ずらす** | 胴と同径では M6 穴の肉が無く、内向きフランジは管の開口を塞ぐ。大径にすると工具も外から届き、ミニガンの「筐体の段」にもなる |
| D-18 | **`assembly()` は員数ぶんの solid をすべて組立座標系に置く。BOM の質量は solid 1 個分、合計は × 員数。solid 数と `PartInfo.count` が違えば fatal。製作品の BOM 行の規格・寸法は `PartInfo` に機種が書く** | 形状・質量・員数が別々に書かれると、組立の出力と BOM が黙って食い違う。数の一致を契約にして build が止める |
| D-19 | **導出値（胴外径・板と管クランプの外径・膜の面密度など）は `SPEC` の葉に持たず、`derive(spec)` で計算する。入力に仮が 1 つでもあれば導出値も仮（面密度は膜の密度 1.39 g/cm³ も仮なので、膜厚が確定しても仮）。§5.2 の外径は式の値を正とする（板 188、管クランプ 160.78。D-17 の「胴外径 + 40 mm」は概算）** | 葉にすると `override()` で入力を振っても導出値が追従しない。`Dim` の算術は出典を落とすので、入力の仮が出力名の `-PROVISIONAL` に出ない |
| D-20 | **外リングを管（手すり用 #400 研磨管 φ25.4 × t1.5）を丸めた環にし、受金を内外リングの間に沈める（上面を「フープの上端 − ロッドの頭の高さ」に置き、頭の上面をリムの上端に揃える。下面は膜面より下に出てよい。内リングと管の両方に溶接）。内リング（リム）は浅く（既定 8、仮。当初 12）、テンションロッドは頭が受金の上面に載り軸が下へ伸びる形にする** | 受金がフープの上に突き出ると叩く・使う邪魔になる。管の環で重機のような見た目にする。口径が小さいほどリムが深いとミスショットしやすい。剛性は管の環と受金の溶接で持たせる。管の曲げは一般的な加工で、費用を大きく上げずに意匠を足せる |
| D-21 | **ラグは胴に 1 本のねじで留める、胴の外から見て丸い単穴のタレット形の既製ラグ**（円盤の軸は胴の半径方向。円盤の中心を胴の内側から 1 本のねじで留め、ロッドは円盤の上の側面から下向きにねじ込む。胴の取付穴は 1 個につき 1 つ。メーカーは固定しない）。D-08 のラグの種類と 2 穴を覆す | 2 穴のラグは取付穴のピッチがメーカーごとに異なり、他社品と交換できなくなる。小口径では 1 点留めで足りる |
| D-22 | **マウントは胴に溶接した当て板 ×2 から出るコの字の管の腕（φ25.4 × t1.5）、後ろの横渡しの中央のブロックの上にホルダー受け、後ろの角にスペードグリップ ×2**。胴バンド・クレードル・ハンドルは無い。D-06 と D-07 の荷重経路を覆す。付け根の曲げの概算は決定ログ | 胴バンドとクレードルは、耳・ボルト・ゴムシート・フレーム・脚が他の部品と何重にも干渉した。バンドは摩擦だけで約 10 kg を支えるので滑る。胴を囲む枠が外観を隠す |

### 3.1 公開リポの決まり

- 非公開の資料・リポ・道具への言及・リンク・URL を置かない。本書も「以前に書いた非公開の道具」より具体的には書かない。

- 第三者の画像（ミニガンの参考画像など）はコミットしない。参考にした事実は文章で書く。
- GitHub: トピック `drums` `drum-hardware` `percussion` `cad` `cadquery` `acoustics` `stainless-steel` `parametric-design`。

## 4. 共通基盤 `cad/drumcad/`

以前に自分用に書いた非公開の CAD 道具から、**そのまま使える部分は抽出し、用途に固有だった部分はインターフェースを新設して一般化**する。
以後は本リポで独立に育てる。

### 4.1 抽出するもの・新設するもの

| モジュール | そのまま使う | インターフェースを新設する |
|---|---|---|
| `dims.py` | `Dim(float)` に出典 `Source` を持たせる仕組み。`measured / spec / design / derived / provisional`、`walk()` `unsettled()` `as_provisional()` | `Source` のラベルを本リポの意味に書き換える（`spec` = メーカー仕様書・カタログ値。証言系の出典は削除）。docstring から元の用途の語を除く。**文字列の選択肢を持つ葉 `Choice(value, source)`** を追加し、`walk()` が拾うようにする（型番・ねじ規格・仕上げ・`tuning_target` が出典と未決判定を持てるように）。`walk()` は dataclass に加え tuple / list / dict / set の中まで降りる（`as_provisional` は同じ型で写し、`init=False` のフィールドに葉があれば `TypeError`） |
| `checks.py`（新規） | — | `Issue(fatal: bool, what: str)`。**fatal が 0 件なら出力可。警告は表示して続行** |
| `drawing/` | 図面の紙面・レイアウト・投影・寸法線・フォント（`view / layout / geometry / fonts`） | 注記・表題欄・図の一覧を**機種が返す**形にする。断面図・平面図の対象は機種が「部品名と切り方（半径方向断面 / 平面外形 / 平面図）」で指定する。員数と一般公差は独立した注記機能にする |
| `viewer.py` | three.js の自己完結 `viewer.html` の雛形（部品ごとの表示切替・視点） | 部品表（部品名 → 表示名・色・不透明度）を機種から受け取る。分解表示（軸方向にずらす）を追加。回転アニメは v2 まで入れない |
| `build.py` | 出力先の stage-and-swap（生成中は一時ディレクトリ、成功したら差し替え、古い出力は `.stale/` へ退避。検査やエクスポートが例外を投げたときも fatal と同じく退避し、機種名つきで報告して次の機種へ進み、最後に失敗した機種を並べて非 0 で終わる）、`-PROVISIONAL` 接尾辞 | 機種をパッケージ名で発見する（§4.4）。2D 出力の切り方と質量計算（部品ごとの材質）を機種の契約から取る |
| `tests/` | build / drawing / viewer / geometry のテストの型 | 機種を差し替え。§1.2(4) の grep テストを追加 |

`Source.provisional` の意味は本リポでは「**まだ決めきっていない値**」。1 つでも残れば出力ディレクトリ名に `-PROVISIONAL` が付く。

### 4.2 新規モジュール

| モジュール | 内容 |
|---|---|
| `materials.py` | `Material(name, density)`。SUS304 = 7.93e-3 g/mm³、A6063 = 2.70e-3 g/mm³（Magnum の逃げ道） |
| `stock.py` | 規格パイプ表（外径 × 肉厚）と丸め。JIS G3446（機械構造用ステンレス鋼管）と手すり用 #400 研磨管（φ25.4 / 31.8 / 38.1 / 42.7 / 50.8 × t1.2 / 1.5）、JIS G3459（配管用）。`nearest(od, t)` は最寄りの規格を `derived` で返し、外径のずれが閾値（既定 1.0 mm）、肉厚のずれが `thickness_tolerance`（既定 0.5 mm）を超えたら警告 `Issue`（どちらがずれても 1 つの `Issue` に両方を書く）。**採用する径・肉厚は `docs/vendors.md` に実在品番で登録してから使う** |
| `acoustics/model.py` | `AcousticModel` の定義。膜（半径・面密度・(0,1) 非結合基音の範囲・損失係数）、プレナム（半径・長さ）、管（本数・内半径・長さ・両端の種別）、観測点 |
| `acoustics/tmm.py` | 伝達行列（ABCD）。円筒セグメント（Keefe の熱粘性損失込み）、面積不連続、並列分岐（同一管 N 本）、開口端の放射インピーダンス（Levine–Schwinger の近似。フランジ付き / 無し） |
| `acoustics/membrane.py` | 円形膜の軸対称モード (0,1) (0,2) の有効質量・有効剛性・有効面積。Bessel 零点は定数表（j01 = 2.4048, j02 = 5.5201）で持ち scipy を入れない。非軸対称モード (1,1) (2,1) は体積変化が無く結合しないので、表示用に周波数だけ出す |
| `acoustics/coupled.py` | 膜 (0,n) ＋ プレナム（短い円筒セグメント）＋ 管 N 本の**結合系の複素固有値**。膜側の空気の付加質量、膜の損失、両開口の放射抵抗を含む。最低根がヘルムホルツ相当、以降が膜寄り・管寄りの根。各根に膜／管の寄与率を付ける |
| `acoustics/synth.py` | 膜の打撃 → 観測点の音圧の伝達関数を周波数領域で組み、ヘッド面と管先端の放射を観測点で複素加算し、逆 FFT でインパルス応答 → 16-bit / 48 kHz の wav |
| `acoustics/report.py` | 共鳴表（Markdown）と sweep の比較表。列は結合系の最低 4 根（周波数・Q・T60・膜／管寄与率） |
| `bom.py` | 部品表。行 = 部品名・製作品／既製品・素材・規格・寸法・員数・型番・質量（製作品の質量は形状から solid 1 個分を出し、合計で × 員数。規格・寸法は `PartInfo` から。既製品は `spec` の値） |
| `process.py` | 工程数量表。レーザー切り部品点数、ロール曲げ回数、TIG 総長、旋削部品数、研磨面積、タップ数。工賃欄は空で、見積もりの項目表として使う。材料費は規格材の m 単価 × 長さ（単価は `docs/vendors.md` から `spec`） |

### 4.3 音響モデルの限界（`docs/acoustics.md` に明記）

- 金属の鳴り（管・胴の機械共振と減衰）は出ない。
- 膜は (0,1) (0,2) の 2 モードのみ。結合系の固有周波数は非結合の膜基音から **20〜40% 動き得る**（プレナムの空気バネが膜の剛性と同程度のため）。絶対値ではなく**構成間の相対比較**にだけ使う。
- 面密度はメーカー非公表なので、膜厚（mil）× 1.39 g/cm³ ＋ コーティングの推定値を `provisional` で持つ。
- 集中定数のヘルムホルツ式は `kL < 0.3` の検算専用。管長 450 mm 級では成り立たないので本計算には使わない。
- 独立実装（`openwind`、または別ファイルの素朴な ABCD）との一致をテストに含める。`openwind` が入らない環境では後者を使う。

### 4.4 機種パッケージの契約

`build.py` は `cad/<機種>/__init__.py` が次を公開していれば発見する。


### 5.3 チェック（`gatling/checks.py`）

入口は `issues(spec)`。形状を作らず、例外も投げない。部品どうしの干渉は `gatling/interference.py` が、形状と同じ placement の値から平面形と z の範囲を作って重なりで見る（平面の幾何は `planar.py`、下限・上限は `bounds.py`）。縁ちょうどの値は通す。

fatal（構造。ここで落ちたら後の検査をせずに返す。後の計算が割れるため）:

- 個数（管・ラグ・フランジのボルト・受金）が整数かつ下限以上（管は 3 本以上、他は 1 以上）。
- 選択肢（フランジ・先端クランプのボルト、ロッドのねじ、ホルダー受けの型）が規格表にある。
- 寸法が正で有限（管の切り詰め代・板径の上限は 0 以上）。符号を問わない葉（周波数の範囲、損失係数、`tube.gap_ratio`、`tube.protrusion_ratio`、`clamp.mid_position`、`flange.bolt_phase`、当て板の方位、グリップの角度）も有限。
- 管の肉厚 < 外径の半分（管束の管と外リングの管）、胴の肉厚 < 胴外径の半分、エッジ環の幅 < 胴の半径（内径が残る）。
- ベアリングエッジの形が成り立つ（角度は 0° 超 90° 未満、幅 > R、R < 高さ、面の落ち < 高さ）。

fatal（寸法の噛み合わせ）:

- 隣り合う管穴の間に肉が残る（管の中心間 − (管外径 + 管穴の逃げ) > 0）。
- ヘッダープレートの外径が胴内径以上（蓋になる。`issues()` からは、板径が胴外径以上に導かれるので恒真）、かつ上限（既定: 胴外径 + 60 mm）以下。
- フランジのボルト穴と管外面の距離が margin 以上（全組で最小を見る）。ボルト穴と板縁の距離が margin 以上。ボルトの頭が胴の外面にかからない（`flange.bolt_seat` ≥ 頭の半径）。
- 管・ラグ・受金の方位が揃う（`tube.count` が `lug.count` の倍数または約数）。受金の枚数がラグの数と同じ。フランジのボルトは、どの管とも同じ方位にない（ボルトと管の方位を全組で比べる）。
- テンションロッドが内外リングの間（`hoop.gap`）を通る（中心半径 ± ロッドの呼び径の半分が、内リングとフレッシュフープの外面の大きいほうと、外リングの管の内面の間にある。管の内面は、軸が通る高さで最も軸に近い所。軸が管の中心の高さを通れば内側の接線）。
- ロッドの頭（受金の上面に載り、上面はリムの上端に揃う）が内リングの外面と、頭の高さでの管の内面の間に収まる（既定で 頭 φ9 の内縁 83.25 > 内リングの外面 80.7、外縁 92.25 < 頭の高さでの管の内面 97.3）。頭の径が受金の穴より大きい（以下だと穴を抜ける）。
- ドラムキーの差し口がロッドの頭に被さる（fatal、`checks.key_socket_fits`）: 頭に差し口を被せた円（中心 = ロッド中心、半径 = `lug.key_socket_dia` / 2）が、頭の z の帯（受金の上面から頭の上面）で内リングの外面と管の内面（その帯での最小半径）の間に収まる。縁ちょうどは通す。既定（差し口 φ13）は内縁 81.25 ≥ 80.7、外縁 94.25 ≤ 97.3 で、内側に 0.55 の余裕が残る（溝 10 では入らない）。
- ロッドの軸の先（受金の上面 − `lug.rod_length`）がラグの上端からねじ込み代（ロッドの呼び径 × 0.75）まで届く。ロッドの必要長は受金の上面からラグの下端までで、placement の高さから出す（既定値で フープの上端から管の下端まで 25.4（管の外径。フレッシュフープの下端のほうが低ければ そこまで）− 受金の上面がフープの上端より下にある分（ロッドの頭の高さ 5）+ 締め代 5 + ラグの高さ（円盤の径）30 = 55.4）。ねじ込み代を満たす最短は 受金の上面 − ラグの上端 + ねじ込み代 = 25.4 + 4.125 = 29.525。既定の `lug.rod_length` は 50（仮）で、軸の先は受金の上面の 50 下（ラグの上端と下端の間）に収まる。
- 受金の上面は「フープの上端 − ロッドの頭の高さ」で、フープの上端から突き出ない（頭の高さが正なら恒真。fatal のまま残す）。受金が外リングの管に届く（受金の上面 > 管の下端）。
- 受金が内リングに溶接できる: 受金の z の帯 [上面 − 板厚, 上面] と内リングの z の帯 [膜面, フープの上端] の重なりが正（0 以下なら fatal）。板厚の半分に足りなければ警告（既定は重なり 3 = 板厚 6 の半分ちょうどで、縁は通す）。
- 受金がフレッシュフープ（半径 `collar`、z は下端から膜面）と平面視でも z でも重ならない。受金の内端は内リングの外面なので、内リングの外面がフレッシュフープの外面より内側（内リングを薄く、掛かりを大きくしたとき）にならなければ満たす。回転体の干渉の検査（`interference.ear_clear`）。
- 内リングがフレッシュフープの上端に掛かり、膜に載らない（`hoop.seat` がフレッシュフープの肉厚以下）。
- 受金の幅がロッド通し穴の径より大きい（以下だと受金が 2 片に割れる）。
- ロッド通し穴の径方向の肉が正: 内側 = (ロッドの半径 − 穴径 / 2) − 内リングの外面、外側 = 受金の z の帯での管の内面の最小半径 − (ロッドの半径 + 穴径 / 2)。0 以下だと穴が受金の端（内リングの円弧、管の切り欠き）を破る（`lug.standoff` を大きくしても出力できてしまうため）。
- 受金とラグの個数の上限: 周に並べて隣どうしが重ならない（幅 ≤ 2 × 内端の半径 × tan(180° / 個数)。受金の内端は内リングの外面（受金はリングの間に沈む）、ラグは円盤の径が幅で、内端は円盤が胴の外面の円で切られる側縁の根元。2 個以下は見ない）。
- 先端クランプの突き出しが 0 以上、中間クランプの比が 0〜1。2 つの管クランプが重ならず、中間クランプがヘッダープレートに食い込まない（比が ヘッダー厚 / 管長 = 6 / 450 ≈ 0.013 未満で食い込む）。中間クランプの中央の穴が残る（PCD − od − 2 × margin > 0）。
- 先端クランプの意匠ボルトの頭が管に当たらない（ボルトと管の中心間 ≥ 管の半径 + 頭の半径）。
- ラグと取付穴が収まる（D-21）: 取付穴 1 つ（円盤の中心の高さ）が胴の上下端（フランジの上面と胴の上端）の内側に収まる。円盤の径 > 取付穴の径（穴が円盤に収まる）。ロッドの通る位置が円盤の厚みに収まる（`lug.standoff` + ロッドの半径 ≤ `lug.depth`）。円盤の径 > ロッドの穴径（ロッドの外縁が円盤の幅の中に入り、肉が残る）。
- マウントの寸法が噛み合う（D-22。`checks.mount_fits`）:
  - 当て板の方位、グリップの落ち角と開き角が 0° 以上 90° 未満（外れたら配置が成り立たないので、ここで返す）。腕の管の肉厚 < 外径の半分。
  - 当て板がプレナムの高さに収まる。板幅・板の高さが腕の管の外径以上。角 R が板幅・板の高さの小さいほうの半分以下。
  - 腕の曲げ半径が管の半径を超える（以下だと掃引が折れる）。曲げの直線部が負にならない: 当て板から最初の曲げまで、後ろへの脚、後ろの横渡しの半分（`placement.arm_bends`。曲げの接点が隣の曲げや当て板の内側に入ると経路が折れ返る）。
  - ブロックが後ろの横渡しの直線部に収まる（ブロックの幅 ≤ 直線部の長さ）。ブロックの高さが腕の管の半径以上。ホルダー受けの本体が、ブロックの幅・奥行きの小さいほうに収まり、ロッド径より太い。
  - グリップの上端がフープの上端を超えない（リムショットの邪魔）。ホルダー受け（つまみを含む）の上端がフープの上端を超えれば警告。
- ボルトの長さ: フランジのボルトがヘッダープレートに届き、突き抜けない。先端クランプのボルトが板を突き抜けない。
- 干渉（D-22。`interference.mount_clear`。z の範囲が重なり、平面視でも重なれば fatal。平面形は形と同じ `placement` の値から作る）。見るのは、当て板（左右）・腕・ブロック・ホルダー受け（つまみを含む）・スペードグリップ（左右）と次の相手:
  - 胴まわりの回転体（胴・エッジ環、フレッシュフープ、内リング、外リングの管（外面、z は管の上端から下端まで）、受金、フランジ・ヘッダープレート、管束とクランプ。外半径の円で見る）。当て板は胴の外面に沿うので、胴・エッジ環との距離は胴の外面として扱う。
  - ラグ（平面形は円盤の矩形。円盤は円柱なので、相手の z の帯に入る薄片の幅で見る。`placement.lug_plan` を各ラグの方位へ回す）。ロッド（軸の先から頭の上面まで。半径 `r.rod` の円周上の円）。
  - 互いに（当て板どうし、当て板と腕、グリップとブロックなど）。腕と当て板は平らな端で接するだけなので、重なりで見る。
  - **見ない組**: 溶接で接する腕とブロック、腕とグリップ（形が腕の外形で切って接する。体積を共有しない）、ホルダー受けの本体とつまみ（1 つの部品）。
  - 平面形は実際の形を覆う凸多角形（見落とさない側）: 腕は直線部を矩形、曲げを 5° ごとの四角形に分けて覆う（`tubepath.plan_polygons`）。傾いたグリップは前後に管の半径ずつ広げた矩形と、端板までを含む z の範囲で見る。
- マウントを付けたままフランジのボルトを抜ける（D-22。`interference.flange_bolts_removable`）: 頭が平面視で当て板・腕・グリップ・ブロック・ホルダー受けのどれかの下に入るなら、その部品の下端とフランジ上面の間に 頭の高さ＋ねじ込み長 の空きがある。既定では腕がボルト（−30°）の上を通り、下端とフランジ上面は 37.3 mm 離れて、必要な 11 mm を満たす。

警告:

- 規格径からのずれ（`stock`。管束の管、外リングの管、腕の管）。
- `tuning_target` に対する管長の達成域と現在値の差（§5.4）。PR 4（音響）で足す。今の `issues()` には無い。
- 腕の曲げ半径が管の外径の 1.5 倍未満（冷間曲げで潰れ・シワが出やすい目安。管の半径以下なら上の fatal）。
- ロッドの軸の先がラグの下端より下に出る（`lug.rod_length` が必要長を超える）。
- ロッドの頭の上面がフープの上端より上に出る（リムショットの邪魔）。受金の上面を「フープの上端 − 頭の高さ」に置くので既定では 0（揃う）で出ない。縁ちょうどは通す。
- 管の外面が胴の内径からはみ出す（開口の一部をフランジが塞ぐ。sweep の `tube.gap_ratio=0.5` で出る。fatal にして NG 行にするかは PR 4 の sweep で決める）。
- ボルトのねじ込みが呼び径の 0.75 倍未満（フランジ・先端クランプ）。
- 受金の幅が、ロッド通し穴の両側に板厚ぶんの肉を残せない（幅 < 穴径 + 2 × 板厚。打ち抜きや穴あけで縁が割れない一般的な目安なので警告にとどめる）。
- ロッド通し穴の径方向の肉（内側・外側とも）が板厚の半分（既定 3 mm）に足りない。穴の両側は内リングと管への溶接で支えられ、幅方向の自由端より緩くてよいので板厚の半分を目安にする。既定の寸法（溝 14、ロッド中心 87.75）では内側 3.8・外側 3.81 mm で目安を満たし、警告は出ない（溝 10 のときは内側 2.05・外側 1.56 で警告が 2 件出ていた。D-20）。両側が目安以上になる `lug.standoff` の範囲は 10.95〜12.56。

### 5.4 音響モデル（`gatling/acoustics.py` → `acoustic_model(spec)`）

- 膜: `head` の半径・面密度・(0,1) 非結合基音の範囲・損失係数。
- プレナム: 内半径 × 長さ（ヘッド面からヘッダープレート上面まで。エッジ環の高さ＋胴高さ＋フランジ厚＋ガスケット厚。既定値で 10 + 100 + 6 + 1 = 117）を短い円筒セグメントとして扱う。
- 管: 6 本を同一管の並列分岐として扱う（1 本の伝達行列を求め、アドミタンスを 6 倍）。開口端補正は 1 本の半径で、プレート側は「有限容積への開口」、先端は「フランジ無しの自由端」。
- 管クランプは空気の共鳴に効かないので入れない。
- 出力: 結合系の最低 4 根の周波数・Q・T60・膜／管寄与率。参考値として非結合の膜 (0,1) (0,2) と、容積 → ∞ の管の `n·c/2L`。インパルス応答 wav（観測点はヘッド面の正面 1 m）。
- **`tuning_target` の定義**（結合系の根で定義する）:
  - `unison`: 膜寄りの根と管寄りの根の間隔が最小（回避交差の中心）。
  - `fifth` / `octave`: 管寄りの最低根が膜寄りの最低根の 1.5 倍 / 2 倍。
  - `octave-below`: 最低根（ヘルムホルツ相当）が膜寄りの最低根の 1/2。
  - 推奨管長は張力範囲の両端で求めた達成域（範囲）として併記する。1 点には決めない。

### 5.5 出力（`cad/out/gatling-6-6[-PROVISIONAL]/`）

- 部品ごとの `*.step` `*.stl` `*.svg`、`assembly.step`、`viewer.html`
- `drawing.dxf` / `drawing.pdf`: 胴・フープ・フランジの半径方向断面、ヘッダープレート・管クランプ・受金・当て板の平面外形（素の 1 枚を員数付き）、腕・ブロック・グリップの平面図・側面図、縦積み図（エッジ環・ラグ・当て板・腕・フランジの高さ関係）、注記（SUS304、TIG と溶接順序、#400 サテン、平面度、既製品の型番と員数、一般公差）
- `bom.md`、`process.md`（工程数量と材料費）
- `acoustics/report.md`、`acoustics/*.wav`
- `build.py gatling --sweep tube.length=400:600:50 tube.gap_ratio=0.3,0.4,0.5`
  で `sweep/` に比較表と wav セット。範囲は `start:stop:step` で stop を含む。
  **fatal な構成は比較表に NG 行として載せ、wav は作らない**。

### 5.6 テスト

- 基盤: `dims` の walk / unsettled が `Choice` も拾う、`stock.nearest` が表を外さない、
  結合モデルが容積 → ∞ で `n·c/2L`、容積 → 0 で `(2n+1)·c/4L` に収束する、独立実装との一致（許容 1%）、

## 6. 検証と製作の段階

1. **形**: viewer で隙間比・クランプ位置を見て決め、`provisional` を `design` に昇格。
2. **音**: 結合モデルの sweep（管長 400〜600、隙間比）を聴き比べ、`tuning_target` と `tube.length` を確定。
3. **既製品**: ラグ・ロッド・ヘッド・ホルダー受けを 1 セット購入して測り、`measured` / `spec` に置き換える。ここで `-PROVISIONAL` が外れる。
4. **図面**: PDF を町工場の目で読む（材料が引けるか、溶接箇所と順序が分かるか、員数があるか）。
5. **見積もり**: `process.md` を項目表にして `docs/vendors.md` の候補へ。
6. **製作順序**（`docs/submission.md` に書く）: 部品単位で研磨まで完了 → 溶接は見えない面から → フランジ合わせ面の平面出し → 管を長めに組み、中間・先端クランプの溶接前に叩いて切り詰める → 局所の酸洗いペーストと #400 手仕上げ。

## 7. 実装の順序（1 PR ずつ）

1. リポ作成（本仕様・README 骨子・ライセンス・スケッチ・トピック・ブランチ設定）
2. `drumcad/` 基盤: dims（Choice 追加）・checks・materials・stock・viewer・build 骨格＋テスト
3. `gatling/`: params・parts・checks・assembly・bom → viewer で形を見る
4. `drumcad/acoustics/`（model・tmm・membrane・coupled・synth・report）＋ `gatling/acoustics.py` → 共鳴表と wav
5. `drumcad/drawing/` の一般化と Gatling の図面・process・`docs/acoustics.md`・`docs/submission.md`・`docs/vendors.md`
6. ヒーロー画像と README 仕上げ
